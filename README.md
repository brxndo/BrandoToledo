# BrandoToledo

Prueba tecnica Angular. Es una aplicación para administrar productos financieros: listar, buscar, agregar, editar y eliminar.

## Ejecucion del proyecto


```bash
npm install
npm start
```

URL:`http://localhost:4200`.

## Pruebas unitarias


```bash
npm test
```

## Porcentaje de cobertura

```bash
npm run test:coverage
```
